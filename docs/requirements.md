# 요구사항

## 목표와 전제

블록체인을 처음 배우는 학생이 거래 생성부터 블록체인 기록까지 직접 조작하고 설명한다. 실제 Bitcoin과의 개념적 차이를 숨기지 않는다. 한 명의 대학생이 이해할 수 있는 React·TypeScript 단일 프로젝트로, Windows·Node.js 24·Chrome/Edge에서 실행한다.

## 기능 요구사항과 확인 위치

| ID | 요구사항 | 화면·검증 |
|---|---|---|
| F01 | 난수 기반 지갑, 공개키·개인키·주소 확인 | 지갑·거래 / 암호 단위 테스트 |
| F02 | UTXO 선택, 수신·거스름돈, 실제 ECDSA 서명 | 지갑·거래 / 정상 송금 테스트 |
| F03 | 형식·서명·소유권·합계·이중 지출 검증 | 검증 결과 / 부정 사례 단위·E2E |
| F04 | 독립적인 노드별 Mempool | 검증·Mempool / 수동 전달 E2E |
| F05 | 실제 Nonce·Hash, 난이도 1~4, 단계·연속 계산 | 채굴 / Worker·브라우저 테스트 |
| F06 | 블록 연결과 거래 탐색 | 노드·블록체인 / 체인 단위 테스트 |
| F07 | A·B·C의 독립 검증·메시지 전달 | 노드·블록체인 / 통합·E2E |
| F08 | 과거 데이터 변조와 해시 재계산 비교 | 변조 실험 / 원본 보존 E2E |
| F09 | 예제·직접 시작, 초기화, 상태 미저장 | 시작·상단 초기화 / E2E |
| F10 | 학습 안내와 Bitcoin 차이 표시 | 모든 화면 / 문서·화면 검토 |

## 최종 확인 조건

- 잠금 파일로 의존성을 설치하고 개발 실행·빌드·미리보기가 동작한다.
- Alice 100에서 Bob에게 30을 보내 채굴·전파 후 모든 노드가 70/30을 계산한다.
- 대기 거래는 확정 잔액을 바꾸지 않는다. 동일 입력의 충돌을 거부한다.
- 실패한 거래·블록은 부분 반영하지 않고 검증 이유를 보여준다.
- 계산 중 화면이 응답하며 중지·초기화가 가능하다.
- 변조 실험은 정상 체인의 복사본에서만 수행한다.
- 타입 검사·린트·핵심 테스트·Chrome/Edge E2E·빌드가 통과한다.
- 실행·설계·단순화·테스트 문서, 결과보고서 초안, 시연 대본·캡처가 제공된다.
