# 요구사항

## 목표와 전제

블록체인을 처음 배우는 학생이 거래 생성부터 블록체인 기록까지 직접 조작하고 설명한다. 실제 Bitcoin과의 개념적 차이를 숨기지 않는다. 한 명의 대학생이 이해할 수 있도록 화면(React·TypeScript, `frontend/`)과 규칙(Python·FastAPI, `backend/`)을 나눈 프로젝트로, Windows·Node.js 24·Python 3.12(uv)·Chrome/Edge에서 한 PC 안에서 실행한다. Node.js는 화면을 빌드하고 수정할 때 필요하고, 실행 중에는 Python 백엔드 하나만 있으면 된다.

## 최종 확인 조건

- 잠금 파일로 화면과 백엔드의 의존성을 설치하고, 두 서버의 개발 실행·빌드·미리보기가 동작한다.
- 화면을 빌드한 뒤에는 Python 백엔드 하나만 실행해도 전체 실습이 동작한다. 빌드된 화면이 없으면 백엔드는 API만 제공하고 빌드 방법을 안내한다.
- Alice 100에서 Bob에게 30을 보내 채굴·전파 후 모든 노드가 70/30을 계산한다.
- 대기 거래는 확정 잔액을 바꾸지 않는다. 동일 입력의 충돌을 거부한다.
- 실패한 거래·블록은 부분 반영하지 않고 검증 이유를 보여준다.
- 계산 중 화면이 응답하며 중지·초기화가 가능하다.
- 검증 실패를 완료로 표시하지 않고 두 번째 거래는 독립된 흐름으로 추적한다.
- 실제 Nonce·Hash 표본을 비교하고 메시지 선택 경로와 실제 다음 전달을 구분한다.
- 변조 실험은 정상 체인의 복사본에서만 수행한다.
- 라이트·다크에서 글자·입력·해시·검증 결과와 UTXO·노드 도식의 상태를 구분할 수 있다.
- 테마를 바꾸거나 시스템 색상 설정이 바뀌어도 실습 상태와 진행 중인 채굴 작업을 유지한다.
- 새로고침 후 테마 선택값은 유지하고, 지갑·개인키·거래·블록체인 등 실습 상태는 초기화한다.
- 브라우저는 화면을 제공한 주소 외의 곳으로 요청을 보내지 않는다.
- Python 구현이 1.1.0 TypeScript 구현의 기준값을 재현한다.
- 화면 버전이 frontend/package.json과 일치하고 백엔드 버전도 같으며, 완료된 업데이트의 실제 버전·날짜·주요 내용을 CHANGELOG에 기록한다.
- 백엔드 테스트·린트, 화면 타입 검사·린트·단위 테스트, Chrome/Edge E2E, 빌드가 통과한다.
- 실행·설계·단순화·테스트 문서, 결과보고서 초안, 시연 대본·캡처가 제공된다.

## 제외 범위

실제 자산·Mainnet·거래소·NFT·Smart Contract·로그인·DB·실습 자동 저장·키 복구·멀티 디바이스·피어 발견·네트워크 분할·동시 채굴·분기 선택·재구성·완전한 분산 합의·최종 영상 촬영. 저장되는 설정은 테마뿐이다. 백엔드는 이 PC의 `127.0.0.1`에서만 요청을 받으며, 여러 사용자·인증·외부 공개 배포와 노드별 별도 프로세스 실행은 다루지 않는다. 퀴즈·난이도 누적 비교는 추가하지 않는다.
