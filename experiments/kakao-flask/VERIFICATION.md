# Flask 2.0.0 검증 기록

검증일: 2026-11-16 (한국 시간). 대상: `codex/kakao-flask-run`의 Flask 앱. 개선 전 기준은 `01b31ad`입니다. 기존 React 앱과 Flask 앱의 버전·실행 경로는 별도로 유지합니다.

## 재현했던 문제와 수정

| 개선 전 문제 | 수정 후 확인한 동작 |
| --- | --- |
| 작성 뒤 수신자·금액을 바꾸어도 이전 거래가 서명·제출됨 | 입력·관찰 노드 변경 시 초안과 서명을 무효화하고 버튼을 잠금 |
| 오프라인 A의 채굴 블록이 B·C에 전파됨 | 분리 상태에서 A만 높이가 증가하고, 연결 후 수동 동기화로 B·C가 따라옴 |
| 직접 수신과 체인 동기화의 난이도 검증이 다름 | 높이별 난이도 정책과 거래 검증을 함께 적용하고 유효한 누적 작업량 비교 |
| 서명 변조 테스트가 서명 없는 faucet 거래를 대상으로 검사함 | 실제 서명된 송금을 변조하고 재채굴 뒤에도 서명 실패 사유를 확인 |

추가한 기능도 별도 담당자가 재검토했습니다. 그 과정에서 확인창을 수락한 초기화 요청이 계산 요청 때문에 누락되는 문제, 새 채굴 작업에 이전 성공 문구가 남는 문제, 다른 서버 인스턴스의 오래된 캐시가 실습 변경을 막는 문제를 재현해 수정했습니다. 단순한 검토자 동의 대신 실제 요청·상태·회귀 검사로 확인했습니다.

## 실행한 검사

Windows, Python 3.13, Node.js 24.19.0에서 실행했습니다. Flask 3.1.3과 ecdsa 0.19.2를 사용했습니다.

| 범위 | 명령 | 결과 |
| --- | --- | --- |
| Python 핵심 규칙·API·저장·실제 서버 재시작 | Flask 폴더에서 `.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v` | 68개 통과 |
| UI 초안·요청 순서·작업 상태·표본·입력 검사 | 루트에서 `node --test experiments/kakao-flask/tests/ui_state.test.mjs` | 10개 통과 |
| 실제 Chrome·Edge 조작 | 루트에서 `npm.cmd run test:flask:e2e` | 브라우저별 12개, 총 24개 통과 |
| 기존 React 앱 영향 확인 | 루트에서 `npm.cmd run check` | 타입·린트·41개 테스트·빌드 통과 |
| 변경 파일 형식 | 루트에서 `git diff --check` | 통과 |

브라우저 검사는 별도 포트 5010과 테스트 DB를 사용했습니다. 지갑 생성 → 지급 채굴 → 거래 작성·변경·재작성·서명·제출 → 채굴 → Alice 30/Bob 70 → B 변조 검출 → 동기화 복구를 실제 버튼으로 확인했습니다. 오프라인 채굴, 한 번 계산·느린 실행·일시정지·재개·중지, 명시적 키 조회·닫기, 초기화 뒤 서명 무효화, 실습 분리·새로고침 복원도 검사했습니다.

초기화·새 실습 확인창의 경합 검사는 실제 서버가 계산한 응답을 잠시 보류한 상태에서 확인을 누른 후, 응답을 전달하고 초기화 요청이 실제 처리되는지 확인합니다. PoW 응답이나 해시를 꾸며내지 않습니다.

1440×1000 데스크톱과 390×844 모바일에서 배치와 가로 넘침을 확인했고, 라이트·다크 화면을 캡처해 직접 살펴봤습니다. 키보드 용어 검색·닫기, 구성도 이동과 테마 유지, 홈을 떠날 때 실제 영상 정지도 검사했습니다.

서버 재시작 검사는 서로 다른 프로세스 ID의 HTTP 서버 두 개를 순서대로 실행합니다. 같은 쿠키의 지갑·대기 거래·실습 ID 복원을 확인합니다. API 검사에서는 저장 실패 시 원복, 이전 revision 거부, 캐시 갱신, 진행 작업 ID와 취소, 재채굴 복사본의 원자적 적용을 확인합니다.

## 유지한 영상과 확인 한계

홈의 기존 자막 영상은 2880×1800, 약 224초입니다. 실제 재생 시간을 검사했으며 파일의 SHA-256은 개선 전과 같습니다.

```text
ffd9654dff2643712161a34756f6368f8e87b39cf6be89b57803ffa4f4859398
```

영상은 이전 UI로 녹화했으므로 화면에도 그 점을 표시했습니다. 최신 UI의 새 시연 영상은 이번 작업에 포함하지 않습니다.

이 검사는 로컬 교육용 축소 모델의 동작을 확인합니다. 실제 Bitcoin 호환성, 다중 서버의 연속 작업 처리, 배포 운영·성능 부하 검증을 의미하지 않습니다. UTXO·수수료·교실 권한 등 기존 본체의 별도 기능을 이 Flask 앱에 합치지는 않았습니다.

## UI 간소화 추가 확인 (2026-11-16)

팀 프로젝트인 Flask 화면만 수정했습니다. 제목·버튼·상태 문구를 짧게 정리하고 문장 끝 마침표, 장식 영문, 중복 소개 카드를 제거했습니다. 상세 규칙은 펼침 영역으로 옮기고 활동 기록의 반복 안내를 생략했습니다. 개인 프로젝트인 기존 본체와 백엔드 규칙은 이번 변경 대상이 아닙니다.

- ESLint와 기존 UI 상태 검사 10개 통과
- 간소화 화면의 Chrome·Edge 전체 E2E 24개 통과
- 최종 제목·버튼 문구 정리 후 Chrome 주요 실습 4개 재검사 통과
- 데스크톱·모바일 캡처 확인, 정적 한국어 문구의 끝 마침표 없음 확인
- 백엔드 문장은 표시 지점에서만 정리하며 주소·키·원본 JSON·소수·URL은 보존
- 시연 영상 SHA-256 동일, AGENTS.md 추가 없음
