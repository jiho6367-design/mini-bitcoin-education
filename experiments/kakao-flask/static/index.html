실제 비트코인과 무엇이 다른가요?

이 앱은 계정 잔액과 거래 순번을 사용하는 교육용 모델입니다. 실제 Bitcoin의 UTXO·Script·수수료·자동 난이도 조정은 구현하지 않습니다. SHA-256과 secp256k1 전자서명, Merkle Root와 채굴 보상을 실습하며, 세 노드는 하나의 서버 안에서 독립된 장부를 보관합니다. 실제 자산이나 P2P 네트워크에 연결되지 않습니다.

실습은 이 브라우저에 연결된 공간에 저장됩니다. 학습용 개인키를 실제 자산에 사용하지 마세요.

FAILURE EXPERIMENT

                  
한 노드의 기록을 바꿔 본다면?

                

                선택 노드의 체인 변경
              

              

                실행 전 대상과 내용을 다시 확인합니다. 정상 이웃 노드가 남아
                있으면 동기화로 복구할 수 있습니다.
              

              

                
              

              

                채굴한 블록이 있어야 변조 실험을 시작할 수 있습니다.
              

              

                
              

              

              

                서명된 송금의 내용을 바꾸면 PoW를 다시 수행해도 원래 서명이 맞지
                않습니다. 거래 #0은 서명이 없는 채굴 보상입니다. 재채굴 중에는
                복사본을 계산하며, 완료 전에 취소하면 원래 체인을 유지합니다.
